# 🧪 功能测试指南

## 快速测试实时新闻和分类功能

### 第一步：启动开发服务器

在项目根目录打开终端：

```bash
npm run dev
```

等待服务器启动后，在浏览器中访问：http://localhost:5173

### 第二步：导航到舆情看板

在应用中找到并进入"舆情看板"页面。

### 第三步：运行测试脚本

**打开新的终端窗口**，运行：

```bash
cd c:\Workplace\zhixun---ai-news-monitor\scripts
python test_insert.py
```

### 第四步：观察实时更新

在浏览器中观察（**无需手动刷新页面**）：

✅ **预期效果：**
1. 3条新的测试新闻应该**自动出现**在页面顶部
2. 时间显示为"**刚刚**"
3. 浏览器控制台（F12）显示日志：`New news item: ...`

### 第五步：测试分类筛选

在舆情看板页面上找到筛选按钮，依次点击：

#### 测试 "全部" 按钮
- 点击"全部"
- 应该显示所有新闻（包括刚插入的3条）

#### 测试 "🔥 高风险" 按钮
- 点击"高风险"
- 应该只显示标题包含 ⚠️ 的高风险新闻
- 其他新闻应该被隐藏

#### 测试 "🤖 科技" 按钮
- 点击"科技"
- 应该显示前2条测试新闻（科技类）
- 人文类新闻应该被隐藏

#### 测试 "🎨 人文" 按钮
- 点击"人文"
- 应该只显示标题包含 🎨 的人文新闻
- 其他新闻应该被隐藏

## 🐛 问题排查

### 如果新闻没有自动出现：

1. **检查浏览器控制台**（按 F12）
   - 看看是否有错误信息
   - 检查是否有 "New news item" 日志

2. **检查 Supabase 配置**
   - 确认 `.env` 文件中的 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY` 正确
   - 确认 Supabase 项目已启用 Realtime 功能

3. **手动刷新页面**
   - 如果实时订阅失败，定时刷新（30秒）应该也能获取新数据

### 如果筛选不工作：

1. 检查浏览器控制台是否有 JavaScript 错误
2. 确认点击按钮时，按钮样式是否变化（深色背景表示选中）
3. 打开浏览器开发者工具的 React DevTools，检查 `activeFilter` 状态
